# Holy Programmer Academy

This repository is the learning archive for the Holy Programmer Academy. It captures the curriculum, progress, notes, and evidence of learning across the fundamentals, systems, and language stages.

## Architecture

- Academy repository = evidence of learning.
- Portfolio project repositories = evidence of engineering.
- Do not mix the two.

This repo tracks concepts, exercises, reports, and milestones. Major engineering work should live in separate repositories such as:

- axiom-kv
- axiom-shell
- soul-process
- axiom-runtime
- ...

## Learning Principles

1. Build understanding before velocity.
2. Write code that can be explained.
3. Keep notes, errors, and reflections.
4. Revisit concepts until they are internalized.
5. Separate curriculum evidence from product engineering evidence.

## Recommended Workflow

- Read the roadmap and track weekly goals.
- Complete the assigned units and capstone work.
- Log mistakes in `ERROR_BOOK.md`.
- Update `PROGRESS.md` regularly.
- Write a brief report in `REPORT_CARD.md` at the end of each stage.

## Stage Overview

### Stage 00 — Machine
Focus on execution models, toolchains, and how programs run on hardware and the operating system.

### Stage 01 — C
Focus on memory, structures, systems-level reasoning, and the fundamentals of low-level programming.

### Stage 02 — C++
Focus on object model, abstraction, RAII, templates, and modern systems design.

### Stage 03 — Systems
Focus on operating systems, concurrency, networking, and deep system internals.

### Stage 04 — Holyc
Focus on the Holyc language and systems philosophy with a practical, minimalistic mindset.

### Stage 05 — C#
Focus on managed software design, tooling, and application architecture.

### Stage 06 — Python
Focus on scripting, automation, data work, and product iteration.

### Stage 07 — SQL
Focus on relational reasoning, schema design, query optimization, and data modeling.

### Stage 08 — TypeScript
Focus on typed frontend/backend engineering and robust application design.

### Stage 09 — Rust
Focus on ownership, safety, performance, and systems-grade application development.
